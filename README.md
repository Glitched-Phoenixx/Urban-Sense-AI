# Pothole Detector V1
YOLOv8 baseed pothole detector

## How to use -
1) Clone the repo
2) Open the folder in cmd
3) paste the following command -    python yolo_pothole_detector.py --detect --weights runs/detect/pothole_yolov8/weights/best.pt --image road.jpg
4) replace --image road.jpg to --webcam to get live feed
